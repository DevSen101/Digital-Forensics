Mail Server - Its a computer within your network that work as your virtual post office.


Note :-
The sender creates the email message using a client program which then sends to this email server. Next the sender's mail server forwards the message to the recepient's mail server. which in turn delivers the email to the receipient's mail client program or webmail.

Sender -> Mail Client Server -> Mail Recipient Server -> Recipient

Protocol used in Email

SMTP (Simple Mail Transfer Protocol) - used for sending e-mail between servers.
It governs the transfer of outbound email from the sending client to the email servers(MDA), as well as the transport of email between servers (MTA). 

IMAP (Internet Message Access Protocol Version 4) - protocol user from sending messages between servers. It governs the transfer of outbound e-mail server from the sending client to the email server (MDA), as well as the transport of email between email servers (MTA).

POP3 (Post Office Protocol Version 3) - used to retreive email messages from an email servers.
- they are inbound mail delivery protocols and are typical client/server protocols. they deliver email from the email server to the email client(MUA).
- Email client connects to the POP3 server and issues a series of commands to bring copies of email messages to your local machine. Generally it will then delete the msgs from the server

DMARC, SPF, and DKIM are email authentication mechanisms used together to stop email spoofing, phishing, and spam. They help mail servers verify that an email claiming to come from a domain is actually authorized by that domain.

DMARC(Domain Based Message Authentication Reporting and Conformance) - is an email authentication protocol. it is designed to give domain owners the ability to protect their domain from unauthorized use, comonly known as email spoofing.

The Sender Policy Framework(SPF) - is an email authentication technique which is used to prevent spammers from sending messages behalf of your domains. with spf org can publish authorized mail servers.

DomainKeys Identified mail(DKIM) - allows senders to associate a domain name with an email address.A sender create the DKIM by signing the email with digital signature. this signature is located in the message header.

Concept of Address Management
Logical Addressing (IP Addressing)
Physical Addressing (MAC Addressing)

IP Address - Internet protocol add is a numerical label assigned to each device connected to computer network. it has to part network id and host id. Ex.IPv4 and IPv6 
Static IP Add : that never change once assigned to a device.
Dynamic IP Add: changes each time device log to a network.

Public IP :- is the address that is assigned to a computing device to allow direct access over the internet.
Private IP :- allocated by inter NIC to allow organisation to create their own private network.

Physical Address Management :- MAC Address :- of a computer is a unique identifier assigned to network interface for communication at the data link layerof a network.
